# StarShip 4 — Vaenlaste lisamine

Allikas: õpetaja „Projekt StarShip 4.docx”, koodipildid.

See on nüüd loodud õppematerjalidel põhinev taastatud versioon, mitte varem säilinud ajalooline commit. Commiti tegelikku kuupäeva ei muudeta.

Eelmised võimalused ning 28 × 28 vaenlased, kiirus 110 px/s ja 0,9 s ilmumisintervall. Tabamusi ega punkte veel pole.

HTML-kest ja 640 × 480 mänguväli on taastamisel valitud; neid mõõtmeid ei kinnita eraldi HTML-näide.

Käivitamine: ava selle kausta `index.html` brauseris. Väliseid sõltuvusi pole.
