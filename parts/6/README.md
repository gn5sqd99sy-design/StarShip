# StarShip 6 — Täisväärtuslik mäng

Allikas: õpetaja „Projekt StarShip 6.docx”, koodipildid.

See on nüüd loodud õppematerjalidel põhinev taastatud versioon, mitte varem säilinud ajalooline commit. Commiti tegelikku kuupäeva ei muudeta.

Kõik võimalused: elud, paus, mängu lõpp, taaskäivitus ning õpetaja raskusastme valemid.

Suurendatud mänguväli on 800 × 600. Kasutatud on kontrollitud lõppversiooni: lisaks õpetaja koodile sisaldab see README-s kirjeldatud ajamärgi, taaskäivituse ja sisendi parandusi.

Käivitamine: ava selle kausta `index.html` brauseris. Väliseid sõltuvusi pole.
